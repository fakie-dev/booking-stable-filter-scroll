# Security

Security fixes are made against the latest release.

Please don't post exploit details, account data, cookies, or other sensitive information in a public issue. If GitHub private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Otherwise, open a short issue asking for a private contact channel without including the sensitive details themselves.

The script has a deliberately small trust surface: `@grant none`, no `@require`, no remote code, no analytics, and no network requests of its own.
